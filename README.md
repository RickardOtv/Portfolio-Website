# 🌐 Portfolio Website

My personal portfolio website to show off my projects and skills.

## What is this?

A simple portfolio site I built to have a place where I can showcase what I've been working on. Clean design, works on mobile, nothing too fancy.

## Features

- Responsive layout (looks good on phone and desktop)
- Projects section
- Skills/tech stack
- Contact info
- Easy to deploy anywhere

## Tech

- HTML
- CSS
- JavaScript

## How to run it

1. Clone it:
```bash
git clone https://github.com/RickardOtv/Portfolio-Website.git
cd Portfolio-Website
```

2. Open `index.html` in your browser — that's it!

If you're using a build tool:
```bash
npm install
npm run dev
```
